အလုပ်ရှင် Dashboard (Employer)

ခလေးထိန်း နှင့် ဖိုးဖွားစောင့်ရှောက်ရေးဝန်ထမ်း ခေါ်ယူရန် တောင်းခံလွှာတင်ခြင်း။

အလုပ်ရှင်များ (Employers) လိုက်နာရမည့် စည်းကမ်းများနှင့် ပယ်ဖျက်ခြင်းမူဝါဒ

ငှားရမ်းပြီးနောက် လိုက်နာရမည့်စည်းကမ်းများ:

  • ခလေး (သို့မဟုတ်) ဖိုးဖွား၏ ကျန်းမာရေးနှင့် လိုအပ်ချက်များကို အပြည့်အစုံ ကြိုတင်မှန်ကန်စွာ အသိပေးရမည်။
  • အလုပ်ချိန်အတွင်း သင့်လျော်သော အစားအသောက်၊ သင့်တင့်သည့်နေရာထိုင်ခင်းနှင့် လုံခြုံရေးကို စီစဉ်ပေးရမည်။
  • သဘောတူထားသော လစာနှင့် ခွင့်ရက်၊ ဂျူတီချိန်များကို တိကျစွာ လိုက်နာပေးရမည်။

တောင်းခံလွှာအတည်ပြုပြီးနောက် ပယ်ဖျက်ခြင်း (Cancellation):

  • Admin မှ တောင်းခံလွှာကို အတည်ပြုပြီး (Confirmed) ဖြစ်သွားပါက အကြောင်းပြချက်မရှိဘဲ ဖျက်သိမ်းခွင့်မရှိပါ။
  • ဖျက်သိမ်းလိုပါက အနည်းဆုံး ၂၄ နာရီ ကြိုတင်အကြောင်းကြားရမည်ဖြစ်ပြီး၊ ပေးချေထားသော အေဂျင်စီဝန်ဆောင်ခ (AGC Fee) ကို ပြန်အမ်းမည် မဟုတ်ပါ။

Super Admin ထံ ပေးပို့ထားသော တိုင်ကြားစာများနှင့် အကြောင်းပြန်ချက်များ

မိမိပေးပို့ခဲ့သော အလုပ်တောင်းခံလွှာများနှင့် ပယ်ဖျက်ရန်

မိမိ၏ အလုပ်လုပ်ကိုင်နိုင်မှု Status သတ်မှတ်ရန်:

Admin များမှ သင့် Status နဲ့ Star Rating များကို ကြည့်ရှု ဆုံးဖြတ်နိုင်ပါသည်

အလုပ်သဘောတူညီချက်များ၊ ဖုန်းအသုံးပြုမှုနှင့် အေဂျင်စီကြေးဆိုင်ရာ မူဝါဒများ

အလုပ်အတည်ပြုပြီးပါက သတ်မှတ်ထားသော နေ့ရက်နှင့် အချိန်တွင် တိကျစွာ သွားရောက် ဝင်ရောက်ရမည်။ အကြောင်းပြချက်မရှိဘဲ ပျက်ကွက်ပါက Blacklist ပြုလုပ်မည်။

၂။ Admin ထံ Agency / AGC Fees ကြေးပေးသွင်းခြင်း

အလုပ်ရရှိပြီးပါက သတ်မှတ်ထားသော AGC Fee များကို Admin ထံ အချိန်မီ တိကျစွာ လွှဲပြောင်းပေးအပ်ရမည်။
